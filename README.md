# TaskFlow — Smart Task Management System

A lightweight, responsive task management web application built using HTML, CSS, and vanilla JavaScript. TaskFlow helps users organize daily tasks, manage priorities, track deadlines, and monitor their productivity through a clean, modern interface.

## Overview

TaskFlow is a front-end project designed to demonstrate practical JavaScript skills, including DOM manipulation, event handling, CRUD operations, data persistence with LocalStorage, and dynamic UI updates.

The application runs directly in the browser without requiring a backend or database server.

## Features

- **Task Management:** Create, edit, delete, and mark tasks as completed.
- **Priority Management:** Organize tasks by priority levels.
- **Due Dates:** Assign deadlines to tasks.
- **Search and Filtering:** Find tasks and filter them by their status or other available criteria.
- **Sorting:** Organize tasks using the available sorting options.
- **Productivity Statistics:** View task statistics to track progress.
- **LocalStorage Persistence:** Keep task data saved in the browser between sessions.
- **Responsive Interface:** Use the application across desktop and mobile screen sizes.
- **Modern UI:** Dark-themed interface with emerald accents and compact task cards.

## Getting Started

### Prerequisites

A modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/maanncodes09/TaskFlow---Smart-Task-Management-System.git
   ```

2. Open the project folder:

   ```bash
   cd TaskFlow---Smart-Task-Management-System
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code for local development.

No package installation or backend configuration is required.

## How to Use

1. Open TaskFlow in your browser.
2. Add a task and enter its relevant details.
3. Set a priority and due date where supported.
4. Update tasks as you make progress.
5. Search, filter, or sort tasks to find what you need.
6. Review your task statistics to monitor completion.
7. Reopen the application later in the same browser to access saved tasks.

## Data Persistence

TaskFlow uses the browser's LocalStorage to save task data locally.

**Note:** LocalStorage is specific to the browser and origin being used. Tasks do not automatically synchronize across devices or browsers. Clearing the browser's site data may remove saved tasks.
